# HFDRSSTC-Plasma-Flame-Generator-
A plasma flame generator, or high frequency dual resonant solid state tesla coil! It uses some really clever electronics to achieve this, and is a staple in plasma physics, being able to produce 4" flames at less than 500W of power. It runs off mains 120VAC, and is based of the IRFP460 power MOSFET. Inspired and derived from the works of Styropyro, Steve Ward, Plasma Channel, and Elecrow.
